# ゆうろーど 街歩き案内

習志野市の商店街「ゆうろーど」の魅力を紹介する、HTML/CSS のシングルページです。外部ライブラリやビルド手順は不要です。

## 表示方法

`index.html` をブラウザーで開くか、リポジトリのルートで次のコマンドを実行してローカルサーバーを起動してください。

```sh
python3 -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開きます。`http://` で配信するローカルページのため、ブラウザーに「保護されていない通信」と表示されることがあります。これはHTTP接続の表示で、ページ自体にログインや個人情報の入力欄はありません。URLが `https://` になっている場合は `http://` に直してください。

Codespacesなどのリモート環境では、VS Codeの「ポート」パネルからポート `8000` を開いてください。
